# MTO Composition

Code for *Methanol-to-Olefins Product Distribution Prediction and Interpretation via Machine-Learning-Based Compositional Regression and Shapley-Composition Analysis*.

## Data availability

The data are available from the corresponding author upon reasonable request.

This repository contains modeling code and parameter settings, without datasets, sample-level predictions, or saved Shapley values. Raw-data curation procedures are not included.

## Run

Python 3.13 was used. Install the dependencies from the repository root:

```sh
python -m pip install -r code/requirements.txt
```

After obtaining the data, create a local `data/` directory and place `train.csv`, `validation.csv`, and `test.csv` in `data/`. The required columns and numeric types are defined in `code/common.py`; responses are percentages summing to 100. Then run:

```sh
python code/experiments.py --stage check
python code/experiments.py --stage score
python code/shapley.py
python code/figures.py
```

The four Python modules contain shared mathematical transforms and data loading (`common.py`), model experiments (`experiments.py`), Shapley compositions (`shapley.py`), and plotting (`figures.py`). The notebooks display results generated by these commands. Outputs are written to `results/` and `figures/` and are excluded from version control.

Full five-fold tuning can be run with `python code/experiments.py --stage all --output results/run`. The seed is 12345. The ILR tree baselines and optimized raw-response ablation controls reuse the corresponding alpha-model learner parameters.

The scoring command fits seven Python models. To include the Dirichlet regression baseline, install R and `DirichletReg` and pass `--rscript /path/to/Rscript`.

`python code/shapley.py --plot-only` regenerates explanation plots after Shapley values have been computed locally.
